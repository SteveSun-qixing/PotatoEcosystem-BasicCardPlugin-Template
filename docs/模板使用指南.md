# 基础卡片插件模板使用指南

## 快速开始

### 1. 复制模板

```bash
cp -r Basic-Card-Plugin-Template Your-Card-Plugin
cd Your-Card-Plugin
```

### 2. 全局替换关键词

使用IDE的全局替换功能（Ctrl/Cmd+Shift+H）:

| 替换内容 | 替换为 | 说明 |
|---------|-------|------|
| `Template` | `YourCard` | 卡片类型名（PascalCase） |
| `template` | `yourcard` | 小写名称 |
| `模板卡片` | `你的卡片名称` | 中文显示名称 |

### 3. 修改关键文件

#### manifest.yaml
- `id`: 修改为你的插件ID
- `name`: 修改为你的卡片名称
- `cardType`: 修改为你的卡片类型
- `config_schema`: 定义你的配置字段

#### package.json
- `name`: 修改包名
- `description`: 修改描述

### 4. 实现核心逻辑

#### 定义配置 (src/types/config.ts)
```typescript
export interface YourCardConfig {
  card_type: 'YourCard';
  // 添加你的字段
  title?: string;
  content?: string;
}
```

#### 实现渲染器 (src/renderer/)
- 实现 `render()` 方法
- 实现内容创建逻辑
- 实现主题应用

#### 实现编辑器 (src/editor/)
- 创建工具栏
- 实现编辑区
- 实现命令处理
- 实现撤销/重做

### 5. 编写测试

```bash
npm test
```

### 6. 构建发布

```bash
npm run build
```

## 常见问题

### Q: 如何通过内核访问资源？

```typescript
const response = await this.core.request({
  service: 'resource.read',
  payload: {
    uri: `chips://card/${cardId}/${filePath}`
  }
});
```

### Q: 如何使用多语言？

```typescript
import { t } from './utils/i18n';
const text = t('yourcard.message');
```

### Q: 如何应用主题？

```typescript
const response = await this.core.request({
  service: 'theme.get',
  payload: { themeId }
});
```
