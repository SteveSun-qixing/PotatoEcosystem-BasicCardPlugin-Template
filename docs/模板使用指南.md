# 基础卡片插件模板使用指南

## 快速开始

### 1. 复制模板

```bash
cp -r Basic-Card-Plugin-Template Your-Card-Plugin
cd Your-Card-Plugin
```

### 2. 全局替换关键词

使用 IDE 的全局替换功能（Ctrl/Cmd+Shift+H）：

| 替换内容 | 替换为 | 说明 |
|---------|-------|------|
| `Template` | `YourCard` | 卡片类型名（PascalCase） |
| `template` | `yourcard` | 小写名称 |
| `TEMPLATE` | `YOURCARD` | 错误码前缀 |
| `模板卡片` | `你的卡片名称` | 中文显示名称 |

### 3. 修改关键文件

#### manifest.yaml
- `id`: 修改为你的插件 ID（格式：`发行商:插件名`）
- `name`: 修改为你的卡片名称
- `cardType`: 修改为你的卡片类型（PascalCase）
- `category`: 修改为合适的分类
- `config_schema`: 定义你的配置字段

#### package.json
- `name`: 修改包名（格式：`@chips/xxx-card-plugin`）
- `description`: 修改描述

### 4. 实现核心逻辑

#### 定义配置 (src/types/config.ts)
```typescript
export interface YourCardConfig {
  card_type: 'YourCard';
  theme?: string;
  layout?: YourCardLayoutConfig;
  // 添加你的字段
}
```

#### 定义错误码 (src/types/errors.ts)
```typescript
export enum YourCardErrorCode {
  INVALID_CONFIG = 'YOURCARD-E1001',
  // 添加你的错误码
}
```

#### 实现渲染器 (src/renderer/)
- 实现 `render()` 方法
- 实现内容创建逻辑
- 实现主题应用
- 建议使用 Vue 3 组件

#### 实现编辑器 (src/editor/)
- 创建工具栏
- 实现编辑区
- 实现命令处理
- 撤销/重做已由 UndoManager 提供

### 5. 编写测试

```bash
pnpm test
```

### 6. 构建发布

```bash
pnpm run build
```

## 项目结构说明

```
src/
├── index.ts          # 入口：导出所有公共 API
├── plugin.ts         # 插件主类：实现 BaseCardPlugin 接口

│   └── index.ts
├── editor/           # 编辑器：编辑模式
│   ├── index.ts
│   └── history.ts    # 撤销/重做管理器
├── types/            # 类型定义
│   ├── config.ts     # 卡片配置结构
│   ├── state.ts      # 运行时状态
│   ├── commands.ts   # 编辑命令
│   ├── options.ts    # 渲染/编辑选项
│   ├── validation.ts # 验证结果
│   ├── constants.ts  # 常量和默认值
│   ├── errors.ts     # 错误码和错误类
│   └── events.ts     # 事件类型
└── utils/            # 工具函数

    ├── validator.ts  # 配置验证
    └── dom.ts        # DOM 工具
```

## 接口导入规范

所有接口从 `@chips/sdk` 导入，这是薯片生态的标准做法：

```typescript
// 标准导入方式
import type { BaseCardPlugin, ChipsCore, PluginMetadata } from '@chips/sdk';
```

**不要**在本地重新定义这些接口。

## 资源访问

通过 `chips://` 协议访问卡片内资源：

```typescript
const response = await this.core.request({
  service: 'resource',
  method: 'fetch',
  payload: {
    uri: `chips://card/${cardId}/${filePath}`
  }
});
```

## 多语言

使用 `t()` 函数获取翻译文本，零硬编码：

```typescript
import { t } from './utils/i18n';
const text = t('editor.placeholder');
```

## 主题

通过 CSS 变量暴露样式接口点，由主题包注入具体样式：

```typescript
import { CSS_VARS } from './types';
container.style.setProperty(CSS_VARS.textColor, '#333');
```
